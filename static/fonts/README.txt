Libron webfonts
===============

Files in this directory are WOFF2 conversions of Libron v0.31, built
unmodified from the upstream source with fonttools (container repack only:
no subsetting, no outline or metadata changes).

  Upstream: https://github.com/nicoverbruggen/libron

Libron is a modified version of Readerly, which is in turn based on
Newsreader. Licensed under the SIL Open Font License 1.1; see LICENSE.txt
in this directory. "Libron" is a Reserved Font Name.

Body text on this site is set in Libron.
